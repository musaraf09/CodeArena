🚀 About The Project

CodeArena is a modern, dark-themed coding platform inspired by popular competitive programming websites.

It provides a clean and interactive environment where developers can explore coding challenges, practice programming, and improve their coding skills.

The goal is simple: make learning and practicing programming more engaging and accessible.

✨ Features

- 🎯 Coding Challenges — Explore programming problems.
- 💻 Code Playground — Write and practice code.
- 🔍 Problem Search — Find challenges easily.
- 🏷️ Difficulty Levels — Easy, Medium, and Hard.
- 📚 Learning Section — Explore programming concepts.
- 📊 Progress Tracking — Keep track of your coding journey.
- 🌙 Dark UI — Modern developer-focused interface.
- 📱 Responsive Design — Works across different screen sizes.
